# 咬合候选区域分割 → Teacher → Diffusion RL

这是独立实验，不替换原有默认模型。入口配置为 `configs/region_point_transformer.json`，输出在忽略目录 `runs/region_point_transformer/`。沿用训练 003、002、005、004、007，验证 006，测试 010、011；排除 001、008、009。不修改 `data/`，不生成体积 SDF。

## 标签与分割

在原始已对齐姿态下，对上下颌分别计算每个原始网格顶点到对颌最近三角面的**无符号欧氏距离**，距离 ≤5 mm 标为正例。不是最近顶点距离，也不依据非封闭网格的内外关系。标签保存在独立 `region_labels.npz`，teacher/agent 的 `case.npz` 不包含标签。

5 mm 正例覆盖约 47%–60% 上颌顶点、57%–75% 下颌顶点，是宽泛的候选区域，可能包含牙龈，不代表真实接触点或临床咬合标注。仅顶点比例受到网格疏密影响，不能解释成表面积比例。

标签始终绑定原始顶点 ID。随机旋转和平移只改变坐标和法向；不会按扰动后的距离重算标签。曲率来自三角网格余切 Laplacian，法向为顶点法向。

分割器使用 [Point Transformer (Zhao et al., ICCV 2021)](https://arxiv.org/abs/2012.09164) 的相对位置编码及逐通道局部向量注意力。这里实现的是三层、单尺度的紧凑版本，含全局 mean/max 上下文，不是论文的完整多尺度编码解码网络。上下颌共享权重，分别输入：

- 4096 个均匀抽取的原始顶点候选 → 无距离权重的 FPS 512 点。
- 坐标、顶点法向、网格曲率、上/下颌类别，共 8 维。坐标按本颌采样中心去中心并除以 30 mm；不输入对颌、当前距离、病例 ID、真实位姿或标签。
- 单颌独立输入刻意消除“必须先对齐才能分割”的循环依赖。它依靠本颌解剖形状预测区域，可能无法推断完全由对颌形状决定的个体化边界。
- 随机旋转向量各分量 ±25°、平移各分量 ±10 mm，训练每轮每颌 8 个新采样/新位姿。不是对所有 SO(3) 旋转的保证；平移由去中心消除。
- BCE + Dice，正例权重只从训练集计算。48 轮，batch 8，width 48，3 层，k=16。仅按 006 的分割 IoU 选择 checkpoint。

完整网格推理时，用当前姿态的 512 个 FPS 点预测，再以三近邻反距离平方插值到原始顶点。测试在 010/011 原始姿态及 near/medium/wide 各 4 个扰动下评估所有顶点，报告 IoU、Dice、精确率、召回率及预测翻转比例。

## Teacher 与 Agent 的接口

分割 checkpoint 冻结并以 SHA256 锁定。每次上颌姿态变化都重新预测；只缓存刚体不变的 FPS 顶点索引，不缓存上颌概率。下颌固定，允许缓存其预测。上下颌分割不读取真实标签或原始正确姿态。实际推理也可直接使用未知姿态的输入 STL。

- 上颌：4096 候选中保留概率 ≥0.5 的点，再按原有距离权重和接触优先规则 FPS 128 点。不足 128 个时补入最高预测概率点，保障固定网络尺寸，不使用真实标签补齐。
- 下颌：取三个顶点平均预测概率 ≥0.5 的三角面，最近三角面距离只在该区域上查询；少于 128 面时补最高概率面。仍保留原始插值顶点法向判定局部距离符号，不重新计算裁剪边界的法向。
- Teacher/agent 输入仍为坐标、顶点法向、曲率、到预测下颌区域的有符号距离，共 8 维；两者共用采样路径。上颌原始完整顶点与转动中心保持不变。
- Teacher 从头训练统一 ranking/calibration 各 32 轮，和上一轮保持相同姿态、质量标签、损失、样本量与网络结构。质量监督仍是恢复原始姿态的误差代理，并非临床咬合质量的独立标注。
- Agent 先进行 2800 次 diffusion 模仿学习更新，再进行 50 轮 diffusion RL；RL 奖励仅为 `2*(新 teacher 分数−旧分数)`。每条轨迹固定 10 步，不拒绝降分动作，也不按精度停止。
- Agent 测试固定 010/011 每个非零档各 32 起点，另加零姿态，共 194 条/采样种子；使用 91001/91002/91003 三个种子，报告全部结果。RL 另与同一随机去噪推理机制的 iteration-0 模仿基线配对比较。

分割率高不保证局部 teacher 排序正确；概率阈值、FPS 点变化及下颌区域边界都可能引入分数不连续。应同时检查局部/近区排序与 agent 真实姿态误差。只有一例验证和两例历史测试病例，结果属于小样本回归实验。

## 运行

仓库根目录，使用已有 Python 环境：

```bash
.venv/bin/python scripts/run_region_experiment.py --config configs/region_point_transformer.json
```

阶段顺序为 prepare → segment → configure → teacher → imitation → rl → evaluate。首次完整运行即可。续接已完成阶段时显式选择余下阶段，例如：

```bash
.venv/bin/python scripts/run_region_experiment.py --stages configure teacher imitation rl evaluate
```

runner 拒绝覆盖已训练的阶段；新实验复制配置并更改 `out`。中断后的 diffusion/ diffusion RL 可通过原 CLI `train-agent --checkpoint .../latest.pt` 恢复；分割训练尚无断点恢复，应使用新输出目录重新训练。日志位于 `runs/region_point_transformer/logs/`。runner 默认 `math_threads=1` 限制 BLAS/OpenMP 线程，PyTorch 仍使用 `torch_threads=4`，避免几何小矩阵计算过度并行。所有模型训练完成后，独立测试任务按 `evaluation_workers=3` 并行执行，可在内存较小的机器上改为 1。

`configure` 生成 `teacher_agent_config.json` 和 `diffusion_rl_config.json`，把分割路径与哈希写入模型配置。训练和推理都需要保留同一个分割 checkpoint，不能只搬 teacher/agent 权重。GPU 上在入口配置设置 `runtime.device="cuda"`，也可设置 `OCCLUSION_DEVICE=cuda`；从 GPU 转到 CPU 推理可设置 `OCCLUSION_DEVICE=cpu`，无需改变已锁定的模型选项；本机实验是 CPU，CUDA 未实测。

对已准备的未知姿态网格进行分割，不需要标签：

```bash
.venv/bin/python -m occlusion_rl_offline.train_regions infer \
  --case runs/region_point_transformer/prepared/cases/010/case.npz \
  --out runs/region_point_transformer/observed_regions.npz
```

输出上下颌每个原始顶点的概率和布尔 mask。新 STL 对先用现有 `prepare` 命令生成网格缓存（包括新增的下颌曲率），再用此命令。通过原 CLI `perturb` 生成未知姿态时会保留下颌曲率。

关键可调参数：5 mm 标签阈值，分割网络宽度/层数/k，采样点数/候选数，增强幅度，训练轮数/学习率/BCE-Dice 权重，预测阈值、插值邻居数、下颌最少保留面数，以及基础配置中的 teacher/agent 参数。改变分割模型或区域规则后必须重新训练 teacher 和 agent，不能套用旧 checkpoint。

自动测试覆盖最近三角面标签、固定顶点标签、注意力梯度、平移/排列一致性、标签不参与推理、checkpoint 哈希检查和扰动缓存字段保留；另执行现有训练/推理回归测试。

完成后可生成汇总表、训练曲线和分割误差空间图：

```bash
.venv/bin/python scripts/report_region_experiment.py
```

报告图需要可选依赖 `pip install -e ".[report]"`。历史实验结果存在时会同时比较原流程，否则仅报告本轮及 RL 内部模仿基线。

## 实际结果

分割验证最优 epoch 44，IoU 0.8814。训练 loss 1.0757 → 0.2697。

| 分割测试位姿 | 上颌 IoU | 下颌 IoU | 上颌 Dice | 下颌 Dice |
|---|---:|---:|---:|---:|
| zero | 0.8670 | 0.8760 | 0.9287 | 0.9339 |
| near | 0.8669 | 0.8761 | 0.9286 | 0.9340 |
| medium | 0.8659 | 0.8755 | 0.9281 | 0.9336 |
| wide | 0.8570 | 0.8683 | 0.9228 | 0.9295 |

| Teacher | MAE | 局部排序准确率 | 近区局部排序准确率 |
|---|---:|---:|---:|
| 原流程 calibration | 0.5207 | 57.25% | 53.85% |
| 区域流程 ranking | 1.0545 | 61.18% | 69.23% |
| 区域流程 calibration | 0.5789 | 65.49% | 65.93% |

| Agent（3 个采样种子均值） | 角度 ° | 平移 mm | 综合误差 E |
|---|---:|---:|---:|
| 原流程 diffusion 模仿 | 2.9043 | 1.0143 | 0.30831 |

| 区域流程 diffusion 模仿 | 3.6938 | 0.8618 | 0.33859 |

综合误差 E = 0.5 × (角度/8° + 平移/4 mm)，主表不含零位姿；各档、零位姿漂移和标准差见 `summary.json`。相同起点已逐项验证，RL 与随机推理模仿基线使用相同采样种子。分割阈值和所有 checkpoint 均不按测试结果选择。

### 结果解释与后续测试

本轮 CPU 实验完成分割 48 轮、teacher ranking/calibration 各 32 轮、diffusion 模仿 2800 次更新以及 diffusion RL 50 轮。Teacher 分别按验证选择 ranking 第 29 轮和 calibration 第 31 轮；模仿与 RL 分别选择第 2800、50 次更新。模仿验证误差为 3.1875° / 0.6710 mm；相同随机推理方式的 RL 初始化验证误差为 2.6208° / 0.6813 mm，RL 最终为 2.4281° / 0.6516 mm。训练末尾仍有改善，不能宣称已经收敛。

**分割有效，但新 agent 整体还未超过旧流程。** 相对本轮相同随机推理的模仿基线，RL 的角度、平移和综合误差分别下降约 3.1%、2.3%、2.9%；相对旧 RL，角度误差增加 21.8%，平移误差降低 13.9%，综合误差增加 7.6%。原始正确姿态执行 10 步后的漂移为 2.9198° / 0.7361 mm，旧 RL 为 2.0091° / 0.8046 mm，仍有明显旋转漂移。本实验不替换原默认模型。

Teacher 固定姿态对的局部排序提升，主要是 010 的近区排序从 41.8% 提高至 67.3%；011 的近区排序反而从 72.2% 降到 63.9%。校准 MAE 从 0.5207 增至 0.5789，零位姿分数锚点 MAE 从 0.6537 增至 0.8399，说明分数数值校准没有改善。

在实际 agent 轨迹的每一步上，用 teacher 分数变化与真实综合误差变化比较方向，新 RL 的方向准确率为 56.03%，旧 RL 为 57.49%；在 teacher 给正奖励的动作中，真实误差反而增加的比例为 35.21%，旧 RL 为 32.81%。这与固定姿态库上的 65.49% 排序率不同：两种评价使用的状态与动作分布不同，不能互相替代。

验证病例 006 的采样检查（原始、near、medium、wide 各 4 个姿态）显示，最终 128 点中属于真实标签区域的比例约 90.6%–93.4%，没有触发上颌补点或下颌补面兜底。区域筛选生效，但仍有误分点。硬裁剪可能丢失有助于旋转恢复的整体形态信息，也可能导致选点不连续；这是待检验的解释，当前结果不能单独证明原因。

下一轮建议按顺序做以下对照，而不是立即增加训练轮数：

1. 固定分割 checkpoint，对比不限制区域、只限制上颌、只限制下颌、双颌均限制，使用相同 teacher/agent 初始权重、姿态样本与训练采样序列，并重复多个训练种子，区分区域筛选与随机初始化的影响。
2. 比较硬阈值筛选与概率软权重，并测试保留少量全局覆盖点；保持最终 128 点和网络容量一致，重点看旋转误差与零位姿漂移。
3. 仅从训练病例采集当前 agent 的实际动作前后姿态对，补入 teacher 的局部排序训练，再在验证病例检查奖励方向。继续保持 agent RL 奖励只来自 teacher，不把测试位姿误差作为奖励或调参依据。

目前只有一个验证病例、两个历史测试病例。三个 diffusion 采样种子不等于三个独立训练种子；这轮是相同预算下的一次流程比较，不是充分的泛化或因果归因结论。

### 验证与产物

28 项自动测试通过。每个策略测试执行 5820 个动作；新 RL 其中 2562 个降分动作全部被执行。RL 训练中执行 4000 个动作，包含 1661 个降分动作。检查了三种子的所有初始位姿一致、每步刚体变换重放、动作片段首动作执行，以及 teacher/分割 checkpoint 哈希。RL 的 144 个 reference/encoder 张量保持不变，38 个 actor 张量发生更新。

另以 010 的未知输入姿态 `[4°, -3°, 2°]` 旋转向量、`[1, -0.8, 0.6] mm` 平移进行了真实推理接口检查。输入目录不含区域标签，推理不读取正确位姿；执行完整 10 步，得到 3.0228° / 0.6231 mm 的残差，并导出恢复 STL。这是接口检查，不替代上述固定测试集统计。
