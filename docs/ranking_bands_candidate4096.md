# 当前 ranking 姿态档位与采样

四档使用无量纲扰动幅度 `m`：接近正确 `[0, 0.1)`、较好 `[0.1, 0.35)`、较差 `[0.35, 1.0)`、明显错误 `[1.0, 2.0)`。每对姿态共用一个随机六维单位方向 `u`，仅从各自区间独立抽取幅度。平移为 `sqrt(6) * m * u[:3]` mm，XYZ 欧拉角为 `2 * sqrt(6) * m * u[3:]` 度。每轮按所有六种有序档位组合生成比较对，包括三个相邻档位比较。幅度的划分只提供合成姿态的排序标签，不等于真实临床咬合分数。因为中间档同时可能成为好/坏样本，当前多档配置将 ranking 的绝对分数锚定权重设为 0，仅优化相对次序。

每个病例从原始上颌网格顶点均匀、不重复地抽取 4096 个候选点；候选索引由 `model.point_seed` 固定，因此同一病例的所有姿态、teacher 与 agent 使用同一候选集合。对每个姿态，只计算候选点到下颌原网格最近顶点的距离，使用该下颌顶点法向决定符号，再在候选集合上执行距离加权 FPS，选出 64 个八通道点。曲率始终取自原上颌网格对应顶点。`model.candidate_points`、`model.point_seed`、`model.fps_strength`、`teacher/agent.fps_points` 可在配置中修改。

旧的 128 点实验、诊断和浏览器回放是历史结果；新采样规则与新姿态对需重新训练 teacher 和 agent 后才可评价准确度。
