# 多随机位姿 agent 与轨迹回放

使用 11 例 teacher 的 calibration 权重训练 PPO agent。训练病例为 003、002、009、005、008、004、007；006、001 用于选权重；010、011 完全留作测试。配置见 `configs/data11_agent_multi_pose.json`。每轮轮换一个训练病例，6 个环境各自随机抽取近（±1.5°、±0.5 mm）、中（±4°、±2 mm）、远（±8°、±4 mm）档位和独立位姿；84 轮共 504 个起点、每条 10 步。奖励始终只等于相邻两步的 teacher 分数差，PPO 不拒绝降分动作。

按验证 teacher 分数增益选出的 agent 来自第 84 轮。在 010、011 留出病例的 64 个宽范围起点上，平均角度误差为 8.062°→8.018°，平移误差为 3.820→3.817 mm，teacher 分数为 -1.659→-1.226，严格 1.5°/0.5 mm 成功率为 0。分数上升并未转化为可靠恢复。

另用独立种子 20261003，逐病例、逐档各测 32 个起点：

近目标区的 64 条测试轨迹均未降低旋转误差；其中原本达标的 17 条在 10 步后全部不达标。这与 teacher 近目标分数方向不稳定的独立测试一致。当前 agent 轨迹用于展示实际学习结果，不代表恢复成功。

在 [多病例轨迹视图](../demo/multi_pose.html) 中可选择 010、011 的近、中、远三档，每档显示独立测试种子的全部 32 条轨迹，共 192 条。页面可按病例、档位、位姿编号筛选，播放或逐步拖动，并显示实际 4096 个均匀候选点与 64 个网络输入点。可在 URL 加 `?case=011&band=8&episode=31&step=10` 直达指定轨迹与步骤。生成脚本是 `demo/generate_multi_pose.py`；旧 010 演示仍在 `demo/index.html`。完整测试 JSON 在 `runs/data11_candidate4096_fps64_more/agent_multi_pose/` 下。
