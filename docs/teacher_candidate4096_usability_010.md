# 010 病例：4096 候选 / 64 FPS teacher 训练与可用性

输入为 010 原始配对上下颌，使用 `runs/case010_mesh128_20260930/case.npz`，从原上颌网格均匀固定抽取 4096 个候选顶点，再按带符号最近下颌顶点距离加权 FPS 取 64 点。上颌顶点法向与网格曲率保留。ranking 比较四档扰动的六类有序姿态对；calibration 的目标是按旋转与平移误差定义的合成质量，不是真实临床咬合评分。

做了两次从头训练：基础配置 `configs/case010_candidate4096_fps64.json` 为 ranking 8 轮、每轮 16 对、验证 16 对，calibration 8 轮、每轮 48 姿态、验证 32 姿态；扩量配置 `configs/case010_candidate4096_fps64_extended.json` 为 ranking 24 轮、每轮 64 对、验证 96 对，calibration 20 轮、每轮 192 姿态、验证 128 姿态。扩量模型的最佳 ranking 为第 20 轮，验证排序 91/96；最佳 calibration 为第 17 轮，验证 MAE 0.492、Pearson 相关 0.898。ranking 在扩量训练期间的验证损失从 0.965 降到 0.288，表明相对排序目标确实继续收敛；最佳 checkpoint 按验证准确率优先、同准确率时验证损失更低选取。

使用 `scripts/evaluate_teacher_usability.py` 和独立种子 20261002 对两个模型做同一批测试：96 对未见过的四档 ranking 姿态（每类 16 对）、128 个 calibration 姿态、64 个接近目标的姿态（角度每轴 ±1.5°、平移每轴 ±0.5 mm）、64 个较大扰动下的纠正步骤，以及 64 个接近目标的纠正步骤。纠正测试将姿态误差缩放至 0.8 倍视为朝目标走，放大至 1.2 倍视为背离目标；只比较 teacher 分数，不涉及 agent。

| 独立测试指标 | 基础 ranking | 基础 calibration | 扩量 ranking | 扩量 calibration |
| --- | ---: | ---: | ---: | ---: |
| 四档姿态对排序 | 65/96 (67.7%) | 69/96 (71.9%) | 84/96 (87.5%) | 82/96 (85.4%) |
| 128 姿态合成质量 Spearman | 0.506 | 0.607 | 0.626 | 0.848 |
| 128 姿态合成质量 MAE | 2.267 | 1.105 | 1.477 | 0.594 |
| 原始姿态分数高于近邻扰动 | 41/64 (64.1%) | 39/64 (60.9%) | 59/64 (92.2%) | 43/64 (67.2%) |
| 近邻范围内质量 Spearman | -0.040 | 0.071 | 0.089 | 0.092 |
| 较大扰动：朝向目标分数高于背离目标 | 44/64 (68.8%) | 46/64 (71.9%) | 46/64 (71.9%) | 62/64 (96.9%) |
| 较大扰动：朝向目标分数高于当前 | 36/64 (56.2%) | 40/64 (62.5%) | 37/64 (57.8%) | 45/64 (70.3%) |
| 近目标：朝向目标分数高于背离目标 | 39/64 (60.9%) | 41/64 (64.1%) | 41/64 (64.1%) | 41/64 (64.1%) |
| 近目标：朝向目标分数高于当前 | 37/64 (57.8%) | 40/64 (62.5%) | 38/64 (59.4%) | 40/64 (62.5%) |

扩量 calibration 六类姿态对分别为：接近正确 > 较好 10/16，接近正确 > 较差 15/16，接近正确 > 明显错误 15/16，较好 > 较差 12/16，较好 > 明显错误 16/16，较差 > 明显错误 14/16。相邻最优两档仍明显弱于跨档比较。

**判断：**扩量 calibration 作为粗姿态区间判别器有一定可用性，但仍不能可靠地作为精确恢复的唯一奖励。尤其近目标区的分数与合成质量几乎不相关，朝目标微调只有 40/64 次比当前姿态加分；以 teacher 分数差为唯一 PPO 奖励时，这些错误方向会直接误导最后的精调。结果仅涉及同一 010 病例的新随机姿态，不能视为跨病例泛化。

权重和完整 JSON 指标保存在 `runs/case010_candidate4096_fps64_extended/teacher/{ranking,calibration}/best.pt` 与 `runs/case010_candidate4096_fps64_extended/teacher/usability.json`。基础训练结果位于相同前缀但不含 `_extended` 的目录。运行独立复测：

```bash
.venv/bin/python scripts/evaluate_teacher_usability.py --config configs/case010_candidate4096_fps64_extended.json
```
