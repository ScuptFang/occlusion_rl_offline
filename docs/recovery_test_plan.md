# 当前 agent 测试与优化计划

基于[当前链路审计](current_pipeline_review.md)与 `configs/data11_contact_fps.json`。本计划取代旧版 SDF 网格/1024 点计划。当前使用下颌原始最近顶点带符号距离、4096 候选、接触优先 FPS64、3 层编码器。

## 固定约束与连续误差目标

1. Agent 环境奖励保持 `reward_scale × (teacher(s_next) - teacher(s))`；下降给负奖励。真实姿态误差和接触几何指标不进入 agent 奖励；PPO 不拒绝降分动作。
2. 每个实验 teacher 与 agent 使用相同候选点、采样数与规则、曲率和法向特征；规则变更要匹配训练。保留原始顶点、顶点法向、网格拓扑曲率，不生成体积 SDF。
3. 主要目标为完整轨迹末端的角度和平移误差越小越好，比较相同起点下两项误差的绝对减少量、均值/中位数/p90及改善比例；不再要求达到固定精度才算有效。旧 1.5°/0.5 mm 仅保留作历史参考统计，不作为选模或停止条件。另报表面点位移 RMS/p95，避免混淆不同 pivot 的平移参数。
4. Agent 不设 STOP 动作、不因达到阈值或 teacher 分数变化而提前结束，每条轨迹执行完整预算步数，每步重新观测并输出动作。允许连续小幅修正，不人为设最小非零动作幅度来强迫抖动；这与提前停止控制循环不同。
5. Teacher 分数增益、最终误差和逐步误差曲线分别报告。零姿态/近姿态测试衡量持续执行中的漂移，不要求 agent 通过停止来保持姿态。

2026-10-01 已执行当前数据上的首轮分阶段优化，见[训练、消融与回归报告](optimization_20261001_report.md)。完成固定起点、teacher 四组训练、PPO 对照/粗细动作/固定 ID/冻结扩量、三训练种子和轨迹演示。Teacher 近区判断与 agent 稳定性仍不足，因此未把失败分支扩大到 20 万步。下文保留完整研发路线；共同坐标变换等变性、完整多尺度局部扫描、FPS128/256、跨来源交叉验证及新患者测试仍是后续项，不能视为本轮已完成。

## P0：冻结基线，补齐数据与评估，优先执行

**产物：数据审计表、固定姿态库、逐步评估 JSON、模型指纹。**

- 固定当前权重、配置、manifest、STL/NPZ 哈希和软件版本。加入采样规则、距离定义、特征版本、模型结构的一致性校验；当前加载器的点数和 state_dict 检查不足以拦截所有同形状异规则的配置。
- 逐例核对单位、上下颌身份、双颌共同坐标方向、法向、截断边界、退化面位置和原始接触图，标注“可作恢复基准/需复核”。不因少量坏面删除病例。
- 几何一致性检查：已知扰动再逆变换应恢复顶点；训练 move、合成扰动和导出矩阵一致；单轴动作/旋转组合正确；共同平移双颌时 teacher 得分不变；共同旋转用于测量 teacher 旋转不变性和 agent 动作等变误差。
- 距离诊断保持生产规则：沿下颌顶点法向正负偏移，检查符号、边界和最近点切换。点到三角面距离只作参考；生产规则变更作为独立实验，不能混入基线。
- 验证 001/006 建立固定起点库：零姿态、近（各轴 ±1.5°/±0.5 mm）、中（±4°/±2 mm）、远（±8°/±4 mm）、单轴、接触/分离/负距离状态。随机档每例至少 128 起点，统一 rotvec 定义，并按实际角度/平移范数分桶；各轴上限不等于总误差上限。
- 每步记录矩阵、teacher 分数、真值误差、动作、选点 ID、更换比例、距离分布。主要汇总最终误差、误差减少量、均值/中位数/p90、最差病例、分数升但误差增比例和后段漂移；阈值成功率仅作参考。初始误差为零时只报告绝对漂移，不计算相对改善百分比。
- 同起点比较初始误差基线、匹配步长随机策略、固定均值动作、当前 agent。初始误差基线只供统计，不是部署时的停止策略。增加 teacher-only 有限步坐标/随机搜索来诊断评分可优化性，按 teacher 调用预算比较；其动作接受机制不应用到 PPO。
- 已知逆变换的受限动作序列仅用于检查步数和动作范围的可达性，不参与训练、奖励或部署性能报告。

**通过条件：** 几何/矩阵检查通过，分档可复现，并与相同起点的初始误差比较。本轮已经复现 4 例零姿态漂移。010/011 后续仅作探索性回归，最终泛化需要新病例。

## P1：优先解决 teacher 局部评分与采样稳定性

### 采样消融

固定点数、候选数、网络与训练预算：

| 组别 | 变化 | 要回答的问题 |
| --- | --- | --- |
| S0 | 当前接触配额 0.5，动态加权 FPS64 | 基线 |
| S1 | 接触配额 0，原加权 FPS64 | 配额边界是否放大跳变 |
| S2 | 从实际初始姿态选点，轨迹内固定顶点 ID | 选点切换对局部方向判断的影响 |
| S3 | 动态采样，训练加入不同候选种子/重复采样一致性 | 能否保留覆盖并降低评分方差 |

S2 teacher 必须训练“初始姿态选点→后续姿态更新特征”的样本，不能从正确姿态选点泄漏目标；需检查长轨迹后是否丢失接触覆盖。先用现有模型定位敏感性，最终比较必须分别重训。仅测试时换采样不是训练消融。

在零姿态和非零随机姿态测试 ±0.01/0.05/0.1 mm、±0.05/0.1/0.5° 微扰，统计选点重叠、得分差、正确修正方向准确率、接触比例、全颌覆盖 p95。同一姿态换候选种子评估分数方差。确认影响后再比较 FPS64/128/256，不同时修改容量、点数与损失。

### Teacher 损失与样本消融

固定一个采样版本：

| 组别 | 方法 | 目的 |
| --- | --- | --- |
| T0 | 当前 ranking→全参数 calibration | 基线 |
| T1 | ranking→冻结网络，仅拟合正斜率标定 | 保留原排序；单调变换不能修复错误排序 |
| T2 | ranking + 连续回归联合训练 | 防止回归遗忘排序 |
| T3 | T2 + 原始锚点 + 局部困难对 + 采样一致性 | 改善峰值和局部方向 |

- 加入精确零姿态，原始/近/中/远比例以 10%/40%/30%/20% 为起点；覆盖单轴、混合轴、不同方向同档比较。近区覆盖不同误差水平与真实动作尺度，不围绕单一达标阈值组织训练。
- 比较固定 margin 与按 `|Δq|` 缩放并截断的 margin；近似同质量样本允许平分。
- rank 增至每病例每轮 128 对（当前 24），calibration 每轮总计 2048 姿态（当前 256），按验证曲线早停。先短预算筛选，再做 3 个训练种子；比较实际样本数/优化步数，不能只比较 epoch。
- Ranking-only 与 calibration 的奖励量纲可能不同；比较 agent 时记录并控制训练集估计的 reward scale，不能把尺度变化误认为排序改善。

**Teacher 研发门槛：** 验证每例近区正确修正方向准确率 ≥90%，原始姿态高于非零近邻 ≥95%，相邻档准确率 ≥85%；微扰/重复采样噪声 p95 小于预定义最小有用修正（0.25°或 0.1 mm）的典型分差。报告分母、幅度与置信区间；若有用修正本身无正分差，直接不通过。

这些门槛只针对原始姿态恢复代理。真实咬合量化需另建人工复核/专家排序集，覆盖接触分布、间隙、明显冲突，并与合成恢复指标分开。

**决策：** teacher-only 搜索若持续偏离原始姿态，先修 teacher；搜索能恢复而 agent 不能，进入 P2。报告搜索多起点和调用量，不能把单次搜索失败直接归因于 teacher。

## P2：在合格 teacher 上优化 PPO

先明确语义和日志，再扩大预算，每项使用同一个冻结 teacher 对照：

1. **预算边界语义：** Agent 始终执行完整预算，不提前停止。若任务定义在固定步数结束，最后一步 bootstrap=0；若训练 rollout 只是持续任务的截断，则保留 bootstrap。边界语义不等于增加 STOP 动作。统一训练/推理/评估 horizon；当前 inference 默认 8，训练测试 10，需要明确指定。
2. **持续动作与细调：** 当前 2°/0.4 mm×10 对照粗→细 2°/0.4 mm→0.5°/0.1 mm→0.1°/0.02 mm，horizon 20/40。阶段按预算或观测选择，不用真值误差切换；每一步都推理并执行连续动作，不加入 STOP、阈值提前结束或降分回退。小动作尺度可能低于 teacher 的可靠分辨能力，要同时检查评分信噪比。
3. **起点分布：** 近/中/远混合，加入零姿态以约束持续控制的漂移，跨病例训练；用固定均值动作检查策略方向偏置。仅在验证集调整比例。
4. **预算：** 5,040→约 50,000→约 200,000 步，分阶段早停，3 个随机种子。先冻结 encoder 训练 actor/critic，再以低 encoder 学习率微调，与全参数 PPO 对照。
5. **日志与有限调参：** 记录 KL、clip fraction、explained variance、actor/critic loss、raw/有界动作熵、动作均值/饱和率。学习率 `{3e-5,1e-4}`、初始 log_std `{-1.5,-0.5}`，依据日志筛选。保留有符号分差，不改成只保留正奖励。
6. **选模：** 按验证集连续误差选择模型。初始方案用 `E = 0.5 × (角度误差/8° + 平移误差/4 mm)`，先逐病例/逐档求均值，再等权宏平均，越低越好。8°/4 mm 是基线归一化尺度，不是达标阈值，尺度/权重在实验前固定并作为超参记录。必须单独报告两项误差，不能用角度改善掩盖平移明显恶化；p90、近区漂移和 teacher 增益辅助判断。真值只用于验证/日志，不进入策略观测和奖励。新 `continuous` 训练栈已实现此选模规则；历史 PPO 栈保留原规则供复现。

**Agent 比较标准：** 在相同起点和完整步数下，优先选择宏平均连续误差更低、两项误差减少量更大且尾部误差更小的方案。另比较第 10/20/40 步误差，检查增加动作是否继续有益或导致反复偏离；中间最优姿态只能作为诊断，不能用真值选择输出或据此提前停止。取消原先 0.2°/0.1 mm、保持率 95%、成功率 80% 等 agent 硬门槛。

若 teacher 局部通过但训练病例仍优化失败，先查 PPO 终止/价值和动作；训练病例好但验证差，再增加病例与跨来源训练。此后考虑最近下颌位移向量/法向等相对几何输入消融，保留曲率并重训两网络。

## P3：泛化与最终评估

- 当前 11 例用于开发，按来源/患者分组交叉验证，避免同患者不同时间/扫描跨 split；同源留出与跨来源留出分别报告。
- 新增未经方案选择的独立病例锁定最终测试，覆盖不同来源、牙列形态、网格密度；增加随机姿态不能代替增加患者。
- 每例每档 ≥128 个固定起点，至少 3 个训练种子。报告病例级配对差异和按病例重采样区间；病例数少时明确限制结论。
- 展示成功、典型失败、最差病例和近姿态漂移轨迹，标注 teacher/agent 权重、采样配置和选点。现有 `demo/multi_pose.html` 为旧采样模型，不能当作当前权重演示。
