# 010 teacher 打分与采样消融

使用 `case010_mesh128` 的 ranking 和 calibration 最佳权重，在**同一病例、未用于训练的新随机姿态**上测试。诊断脚本为 `scripts/diagnose_teacher_010.py`，随机种子 20261001；近范围（各轴 ±1.5°、±0.5 mm）、中等范围（±4°、±2 mm）、全范围（±8°、±4 mm）各 24 个姿态。另用新随机种子构造 24 对与 ranking 训练同规则的近/远姿态。所有实验保留原上颌网格顶点曲率、128 个输入点和相同的模型权重。

| 指标 | Ranking | Calibration |
|---|---:|---:|
| 近/远配对正确 | 23/24 | 22/24 |
| 近/远平均分差（好−坏） | 0.0301 | 0.0307 |
| 原始姿态分数高于扰动姿态 | 72/72 | 71/72 |
| 72 个姿态：分数与合成质量的 Spearman 相关 | 0.465 | 0.574 |
| 质量差 >0.5 的跨姿态配对正确率 | 0.704 | 0.763 |
| 近范围内部的 Spearman 相关 | 0.037 | 0.064 |
| 中等范围内部的 Spearman 相关 | −0.021 | −0.015 |
| 全范围内部的 Spearman 相关 | −0.024 | 0.087 |
| Calibration 对合成质量的 MAE | — | 0.968 |

**判断：**ranking 阶段能区分训练定义的明显近/远姿态；calibration 改善了跨范围排序。两阶段对*同一扰动范围内部*的误差大小几乎没有单调性，平均近/远分差也很小。因此 teacher 作为粗略好坏判别器有信号，但作为逐步恢复原姿态的精细奖励还不正常。这个发现与当前 agent 在 010 上 0/32 达标、角度误差上升一致。校准训练保存的验证 MAE 为 1.126；这里的 0.968 来自另一个新随机姿态集，样本量及分布不同。

推理期消融保持已训练的权重不变。`spatial_fps` 在全部上颌顶点上执行纯几何 FPS（距离权重强度设为 0）；`uniform_pool` 将三个距离加权池化分支改为均匀平均；`reversed_pool` 保留权重分布但颠倒其与点的对应关系。结果如下：

| 消融 | Ranking 相关 / 配对正确率 | Calibration 相关 / 配对正确率 |
|---|---:|---:|
| 原始距离加权 FPS + 距离加权 pooling | 0.465 / 0.704 | 0.574 / 0.763 |
| 纯几何 FPS | 0.075 / 0.526 | 0.138 / 0.567 |
| 均匀 pooling | 0.444 / 0.705 | 0.552 / 0.763 |
| 颠倒 pooling 权重对应关系 | 0.436 / 0.704 | 0.567 / 0.779 |

距离加权 FPS 把 `|距离|<0.6 mm` 的点占比从纯几何 FPS 的 **5.25%** 提升至 **22.57%**，负距离点从 **3.91%** 提升至 **18.34%**；同时它显著改善两阶段在这批姿态上的排序，因此对**当前权重**有用。距离加权 pooling 被替换后排序几乎不变，未观察到明确贡献。该消融没有分别重训替代模型，不能证明均匀 pooling 在重新训练后一定更好，也不能推断到其他病例。

