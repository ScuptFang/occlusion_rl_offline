# 原始区域网格 → 10240 顶点候选 → 256 点 FPS

本实验在分割之后先恢复 STL 原有的顶点和三角面，再做 teacher/agent 的采样。沿用上一轮冻结的 PointTransformer 分割器，重新训练 teacher 和 agent。RL 使用 ranking 阶段的 teacher，不使用第二阶段 calibration 权重；calibration 仍训练并测试，作为 teacher 评分对照。

## 数据顺序与网格索引

1. 加载原始 STL，合并重合三角角点，建立共享顶点表；STL 本身没有共享顶点编号。保存 `upper_faces`、`lower_faces`，保留原始面片顺序，并逐面核对与原 STL 相同。
2. 在当前姿态对单颌预测分割概率，映射到完整原网格的所有顶点。分割器仍使用原有 4096 候选 / 512 FPS 设置，10240 / 256 是后续 teacher 和 agent 的输入设置。
3. 默认 `face_rule=all`，三个顶点概率均 ≥0.5 才保留该原始三角面。取保留面片引用的顶点，建立紧凑子网格，保留 `vertex_ids` 与 `face_ids`，满足 `vertex_ids[faces] == original_faces[face_ids]`。不生成新三角面、不重新网格化。
4. 在恢复出的上颌区域网格内，均匀抽取 **10240 个不同的原顶点**，再按原有距离权重与接触优先 FPS 选取 **256 个不同顶点**。区域不足 10240 时明确失败，不从区域外补点、不重复点。
5. 下颌也恢复原始区域子网格。距离取到其原三角面表面的最近距离，使用原始顶点法向的插值确定局部符号，不使用体积 SDF。
6. 法向和曲率沿用原完整三角网格计算结果，避免裁剪边界导致法向/曲率改变。点坐标、顶点法向、曲率、局部有符号距离组成 8 维特征，teacher 与 agent 共用同一采样实现。

每次上颌姿态变化都重新预测分割区域、恢复面片并采样。仅缓存刚体不变的分割采样索引和插值权重，绝不缓存上颌预测概率。固定下颌可缓存区域。整个流程不读取真实区域标签或原始正确姿态；原始完整上颌顶点的均值仍作为转动中心。

若预测面片少于 `minimum_upper_faces` / `minimum_lower_faces`，按面片最低顶点概率补到最低面数，保留审计标记。本轮 8 病例 × 4 姿态的数据检查未发生这种补齐；上颌区域有 63870–92189 个顶点，全部能提供 10240 个候选。

原始姿态的区域网格与映射保存在本地 `prepared/cases/<ID>/upper_region.stl`、`lower_region.stl` 和对应 `.npz`；它们是检查用输出。训练/推理不会直接读取这些原始姿态区域，而是从每一步实际输入姿态重新预测。

## 已发现的采样稳定性问题

对验证病例 006 的微小姿态变化进行原始顶点 ID 审计：绕 x 轴转 0.05° 时，区域顶点集合的 Jaccard 重合率为 99.994%，但 10240 候选集合只有 13.73%，最终 FPS 集合只有 2.61%。平移 0.01 mm 时区域和候选集合不变，FPS 集合重合率为 31.96%。Jaccard 是交集/并集，不是保留点比例。

原因之一是区域顶点列表改变后，按固定 seed 在该列表中均匀抽样会重新排列候选身份。这是当前确定性采样规则在变化区域上的不连续性，不是生成了新的网格顶点；所有候选始终来自原 STL。距离加权 FPS 本身也会随姿态变化而改变选点。这可能影响局部 teacher 奖励的稳定性，但单个病例的探针不能量化它对最终误差的贡献。

本轮完整保留该规则完成训练和测试，没有中途切换采样分布。后续应对照测试“为原始顶点固定随机优先级，再在预测区域中选前 10240 个”的规则，减少边界微变导致的大量候选替换；更换后需要重新训练 teacher 和 agent。

## 实现与推理验证

- 31 项测试通过，覆盖源网格顶点/面片索引、准备和扰动后面片保留、姿态改变后重新分割，以及 teacher/agent 输入一致性。
- 在真实扰动后的 010 输入上单独执行推理，不提供原始目标位姿：起始 6.708° / 1.414 mm，10 步后 2.781° / 0.574 mm。该例用于验证推理接口，整体效果以完整测试为准。
- demo 的 50 条轨迹共 500 个动作，216 个降分动作照常执行；逐帧重算分数与测试记录差异为 0。全部 256 个实际输入顶点均属于该帧的 10240 个原网格候选顶点。
- 浏览器已检查播放、步进、滑块、病例/扰动档切换、视角、移动布局和对应旧版对照链接，无 JavaScript 错误。点击“打开 128 点对照”会打开相同病例、起点和步数。
- 训练完成 32 轮 ranking、32 轮 calibration、2800 次模仿更新、50 轮 RL。RL 共执行 4000 个动作，其中 1687 个降低 teacher 分数；选用验证集最优第 20 轮，144 个冻结编码器/参考策略张量保持不变。

## Teacher 测试结果

测试 010、011 的 512 对位姿，其中 255 对符合局部比较条件、91 对符合近区条件。

| Teacher | 分数 MAE ↓ | 局部排序准确率 ↑ | 近区局部排序准确率 ↑ |
|---|---:|---:|---:|
| 旧 4096/128 ranking | 1.0545 | 61.18% | 69.23% |
| 新原网格 10240/256 ranking | 0.8583 | 57.25% | 50.55% |
| 旧 4096/128 calibration | 0.5789 | 65.49% | 65.93% |
| 新原网格 10240/256 calibration | 0.4157 | 60.78% | 52.75% |

Ranking 训练损失从 0.5576 降至 0.2054，选择验证集第 31 轮；calibration 从 0.6263 降至 0.1753，选择第 24 轮。训练损失下降，但局部排序测试表现变差，不能将损失收敛等同于奖励精度提高。新 ranking/calibration 的 Spearman 分别为 0.9315/0.9413，说明全局趋势较好，但接近正确姿态时仍缺乏可靠的精细排序。

本轮 agent 按既定方案使用新 ranking 权重。建议后续优先验证候选点稳定性和近区困难样本，再比较 calibration 奖励；不应仅凭点数增加继续扩大模型或训练次数。

## Agent 分档结果

010、011，三个推理种子，固定 10 步，以下按非零扰动轨迹计算均值。每个策略共 582 条轨迹（含 6 条零位姿检查）、5820 个动作。

| RL 扰动档 | 旧 4096/128 角度 ° / 平移 mm | 新原网格 10240/256 角度 ° / 平移 mm |
|---|---:|---:|
| 近区 | 2.4753 / 0.6308 | 2.1826 / 0.5424 |
| 中区 | 2.9918 / 0.7320 | 2.9374 / 0.6590 |
| 大扰动 | 4.5100 / 1.1407 | 4.9756 / 1.1794 |
| 总体 | 3.3257 / 0.8345 | 3.3652 / 0.7936 |
| 正确位姿起点的最终漂移（单列） | 2.7241 / 0.6820 | 2.3214 / 0.5668 |

新 RL 相对旧 RL 平移误差降低 4.90%，角度误差增加 1.19%，综合误差 E 从 0.31217 降至 0.30952（降低 0.85%）。近、中扰动改善，大扰动变差；单个训练种子的差异不足以证明稳健收益。正确起点依然发生漂移，说明持续执行动作时，策略的局部稳定性尚未解决。

新 RL 实际轨迹上的逐步 teacher 奖励方向与真实误差改善方向一致率为 60.27%（旧版 54.28%）；在 teacher 分数上升的有效动作中，28.84% 的真实误差反而增大（旧版 34.87%）。这与固定测试位姿对的局部排序指标属于不同分布，不能相互替代。共 2443 个测试降分动作仍正常执行。
