# 逐步闭环的 Diffusion Policy 实验

本分支测试条件动作扩散能否替代现有 PPO 的动作预测。参考 [Diffusion Policy 项目](https://diffusion-policy.cs.columbia.edu/)和[官方实现](https://github.com/real-stanford/diffusion_policy)：从专家动作序列学习条件去噪，再滚动执行短期动作计划。本项目使用点云 encoder 和条件残差 MLP，未复现官方 temporal U-Net / 图像输入。它是监督模仿学习，不是 DPPO，也没有把普通 PPO 的高斯 log-prob 套用到扩散采样链。

## 每一步如何恢复

1. 对当前上颌姿态按原规则采样：4096 个原网格候选顶点 → 接触优先 FPS 128 点。输入仍为 XYZ、顶点法向、网格曲率、下颌最近顶点法向定义符号的距离，共 8 维。
2. 三层 teacher encoder 生成 324 维特征，加当前步数/剩余步数的 2 维上下文。网络不输入真实姿态误差、原始上颌目标点云或专家动作。
3. 从高斯噪声开始，用 20 步 DDIM（eta=0）去噪，联合生成未来 4 步、每步 6 维的归一化动作。仅执行第 1 步，动作范围与 PPO 一致：旋转向量每分量最多 2°、平移每分量最多 0.4mm。
4. 重新读取动作后的点云，再预测下一段。每一步都重规划，不缓存执行整段。执行完整外部步数预算，不因误差阈值或 teacher 降分停止/回退。

[DDIM](https://arxiv.org/abs/2010.02502) 的反向采样在给定初始噪声后是确定的；不同 `sampling_seed` 会产生不同动作。每次预测只计算一次点云特征，去噪循环复用该条件特征。对估计的干净动作裁剪到 [-1,1] 后重新计算 epsilon，保持 DDIM 更新一致。最后的 t=0 更新直接输出干净动作，不遗留噪声。

配置为 `configs/diffusion_policy.json`。Diffusion agent 总参数 1,047,912，可训练参数 1,027,047；去噪/条件网络参数 970,916。原 128 点 PPO 总参数为 248,017。两者容量不同，这不是等参数量的架构对照。

## 数据和训练

沿用 7 例训练（003、002、009、005、008、004、007）、2 例验证（006、001）、2 例测试（010、011）的病例划分。只使用训练病例生成离线数据：每例 64 个随机起点、每条 10 步，合计 4,480 个观测/动作序列样本。起点分布沿用原零/近/中/远档位；收集时 80% 执行专家动作、20% 执行随机动作，以增加偏离专家路径的状态。每个访问状态重新生成后续 4 步专家标签。

专家使用训练时已知的合成位姿计算逆旋转和平移。未来标签按真实环境的左乘旋转、独立平移约定递推；只生成动作标签，不把未来点云送入模型。动作预测窗可以延伸到 10 步执行预算之后，标签是合法的专家延续，不使用跨病例拼接或零填充；达到原位后自然产生零标签，轨迹本身不会提前终止。

训练使用 100 个 cosine 噪声时间步、epsilon MSE、AdamW、梯度裁剪和 EMA。默认 2,800 次更新，batch=64，总计 179,200 次样本呈现，每 280 次更新在验证集执行完整轨迹，按几何综合误差 `E=0.5×(角度/8°+平移/4mm)` 选择 EMA checkpoint。encoder 从已有 128 点 teacher 初始化并以 1e-5 学习率更新，去噪网络学习率 3e-4；teacher 始终冻结，仅用于初始化与轨迹评分，不提供本轮训练奖励。

这里与 PPO 的训练目标、访问状态、优化预算和参数量都不同。对照用于比较两条实际训练栈的恢复结果，不能把差异单独归因于扩散模型。teacher 与 PPO 使用上一轮已训练的 128 点权重，本轮不重训 teacher。

主要超参全部位于 `agent.diffusion`：预测窗、噪声/推理步数、隐藏宽度/层数、时间嵌入维度、更新次数、batch、每例轨迹数、收集 batch、随机动作概率、学习率、encoder 学习率、EMA、权重衰减、梯度裁剪、验证间隔和采样种子。采样密度和规则仍由 `agent.fps_points`、`teacher.fps_points`、`model` 共同控制。

## 命令

本机复用原网格缓存和已训练的 128 点 teacher：

```bash
.venv/bin/python -m occlusion_rl_offline --config configs/diffusion_policy.json train-agent \
  --manifest runs/data11_candidate4096_fps64_more/prepared/manifest.json

.venv/bin/python scripts/evaluate_diffusion.py \
  --manifest runs/data11_candidate4096_fps64_more/prepared/manifest.json

.venv/bin/python -m occlusion_rl_offline --config configs/diffusion_policy.json infer-agent \
  --case path/to/observed_case.npz --out runs/diffusion_policy/inference --steps 10
```

新机器先用 `prepare-batch` 从外部 STL 建立缓存，再用 128 点配置的 `train-teacher` 训练教师；以上命令显式传入新的 `--manifest`、`--teacher` 路径。PPO 对照需要另外按 `configs/reagent_curriculum_large.json` 训练，评估脚本可用 `--baseline-config`、`--baseline` 指定。权重与数据不随 Git 发布。GPU 在统一 CLI 子命令之前增加 `--device cuda:0`；脚本也接受 `--device cuda:0`。本机仅验证 CPU。

训练恢复在原 `train-agent` 命令追加 `--checkpoint runs/diffusion_policy/agent/latest.pt`。恢复 optimizer、原始模型、EMA 和 RNG，保持原总预算与配置，不支持通过续训改变目标预算。离线缓存校验配置、manifest 和训练病例内容哈希；配置或数据变更时使用新输出目录，避免复用过期标签。中断后从最后一个验证 checkpoint 恢复，checkpoint 之间的更新会重跑；数据收集尚未写完缓存时需要使用新输出目录重新收集。

## 轨迹与测试

`evaluate_diffusion.py` 固定初始位姿 seed=426201，010/011 各 near/medium/wide 三档、每档 32 条，加两条原始位姿；每条执行 10 步。对比相同 128 点密度、相同 teacher、相同动作尺度的 PPO。Diffusion 使用 91001、91002、91003 三个采样种子，全部报告，不按测试误差选择种子。这只是推理噪声重复，不是三个独立训练种子。

完整轨迹保存在忽略目录 `runs/diffusion_policy/test/*_trajectories.json`。每条包含：

- 初始旋转/平移和原网格 pivot；每一步实际旋转、平移、teacher 分数、角度/平移误差及采样顶点 ID。
- 每一步预测的 `planned_actions[batch,4,6]`，以及实际执行的 `action[batch,6]`，后者恒等于计划第一个动作。
- 几何有效性、动作执行标志。评分降低不会使动作被拒绝。

`comparison.json` 保存逐步均值、最终误差、各病例/档位结果、checkpoint/teacher/manifest 哈希及三个采样种子的均值和标准差。评估中的旋转/平移以原网格 pivot 为中心，世界变换为 `[R, pivot+t-R@pivot]`；这些真实误差和姿态仅由评估器记录，不送入策略。独立 `infer-agent` 只需要观测病例，导出每一步的累计 4×4 变换和动作计划。

自动测试覆盖 cosine 噪声日程、理想噪声预测器精确恢复动作、encoder/去噪网络梯度、专家序列与环境变换一致、保存加载、训练中断逐位复现、完整逐步轨迹、只执行计划首动作、无目标位姿的推理与错误配置拒绝加载。既有 PPO 测试继续运行。

测试病例历史上已经用于分析，010 还曾用于其他单病例训练；本次是按当前划分留出的回归测试，不是全新外部泛化验证。

## 实际结果：2026-10-12

CPU / PyTorch 2.8，训练种子 61001。完成 2,800 次更新；第 280 次更新区间的平均 epsilon MSE 为 0.25559，最后一个区间为 0.08484。验证几何 E 从 0.72749 改善至 0.34506，选中第 2,800 次更新的 EMA 模型（2.8357° / 1.3426mm）。同密度的 PPO 验证最优为 2.2533° / 1.2273mm、E=0.29424，**验证集上扩散模型仍较差**。最终验证还在改善，不能宣称已经充分收敛。

锁定模型后运行测试；各行均为 192 个随机起点、每条 10 步的非零档位宏平均，原始位姿另行统计：

| 模型 / 采样种子 | 角度误差 ° | 平移误差 mm | E |
|---|---:|---:|---:|
| 初始姿态 | 4.3929 | 2.0526 | 0.53113 |
| ppo | 3.2097 | 1.1308 | 0.34196 |
| diffusion_91001 | 2.9979 | 0.9361 | 0.30438 |
| diffusion_91002 | 2.9618 | 0.9628 | 0.30546 |
| diffusion_91003 | 2.9226 | 0.9415 | 0.30035 |
| 扩散三个采样种子均值 | 2.9608 | 0.9468 | 0.30340 |

相对相同 128 点输入的 PPO，扩散的测试平均角度误差下降 **7.8%**、平移下降 **16.3%**、综合 E 下降 **11.3%**。
三个采样种子的整体角度/平移均值标准差为 0.0307° / 0.0115mm；它不能当作病例泛化的置信区间。测试与验证的优劣顺序不同，且训练预算/网络容量并不一致，因此保留为独立实验配置，不替换原 PPO。

| 1 | 3.7918 / 1.8692 | 3.9271 / 1.8479 |

扩散的平均平移误差持续下降，平均角度在后半程继续改善；这些均值不代表每条轨迹或每个动作都改善。分档结果更能显示限制：

| 档位 | PPO ° / mm | 扩散三种子均值 ° / mm |
|---|---:|---:|
| zero | 1.5704 / 0.6079 | 1.5273 / 0.7178 |
| near | 1.5275 / 0.6614 | 2.2365 / 0.7247 |
| medium | 2.8306 / 0.8586 | 2.5593 / 0.7848 |
| wide | 5.2711 / 1.8723 | 4.0864 / 1.3309 |

**收益集中在 medium/wide，near 档反而退化，原位仍有漂移。** 三次采样的 zero 档平移误差分别为 0.3522 / 1.0601 / 0.7411mm，单个近正确状态对噪声的敏感性明显大于总体均值的波动。按病例/档位平均的角度 P90 为 5.3362°，高于 PPO 的 4.9629°；平均角度改善也未覆盖尾部风险。

扩散相邻动作的旋转向量差/平移向量差平均范数为 1.6192° / 0.4188mm，PPO 为 0.4952° / 0.1056mm，说明动作变化更大。该指标是全部轨迹相邻动作向量的变化幅度，并非按真实时间计算的加速度。当前每步重新采样噪声可能贡献波动，但本实验没有证明其因果占比。

离线标签中约 **46.0%** 的首动作近零（最大分量绝对值 <1e-5），是专家收集轨迹快速回到原位造成的。下一步应先在训练/验证集比较状态采样平衡、更多训练更新及观测历史，再检验降低逐步采样波动的方案；若要加入教师奖励强化微调，应实现专门的 diffusion policy optimization，而不是直接复用当前 PPO 的单高斯概率比。这些优化尚未在本轮执行。

16 项自动测试全部通过。另逐一重放检查了 PPO 和三次扩散测试的 **7,760 个实际动作**：动作边界有效、全部执行，记录的下一姿态与环境旋转/平移公式一致，扩散动作全部等于当步预测计划的第一个动作。三个扩散测试分别包含 749 / 782 / 769 次 teacher 降分动作，均未拒绝。独立 010 扰动输入推理也完成 10 步，其中 5 次降分，未输入目标姿态。
